# 消融实验目录

本目录按数据集组织实验结果，用于回答“Full 模型中的各模块是否必要”的问题。

## 数据集

```text
zenodo_floating_wind_fmea/
磷酸铁锂电池DFMEA/
```

每个数据集目录下保存该数据集对应的 Full 与 Full-Mi 结果：

```text
Full_全量模型/
Full-M1_去除CSV直答模块/
Full-M2_去除确定性规则问答模块/
Full-M3_去除查询理解与检索增强模块/
Full-M4_去除证据检查与路由裁决模块/
```

两个数据集均保留残差模型：

```text
Full-ΣMi_残差模型/
```

该目录用于检查关闭全部已定义模块后的残差模型是否接近固定 Baseline。

## 模块定义

| 模块 | 说明 |
| --- | --- |
| M1 | CSV 直答模块 |
| M2 | 确定性规则问答模块 |
| M3 | QueryIR 与语义检索增强模块 |
| M4 | 证据检查与路由裁决模块 |

## 模块专项实验

模块专项实验放在各数据集目录内部：

```text
zenodo_floating_wind_fmea/模块专项实验/
磷酸铁锂电池DFMEA/模块专项实验/
```

它们用于补充主消融实验，说明每个模块对应的现实问题是否被针对性解决。
