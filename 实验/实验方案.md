### 2.4 反效果 / 不能起论证作用（需处理）

| 结果 | 数值 | 处理方式 |
|---|---|---|
| M4 主实验负增益 | Full-M4 91.73% > Full 90.47%（电池 98.00% > 97.80%） | 改口径：M4 定位为「控制证据不足场景的错误输出」而非「提升准确率」；主实验题集补证据不足类题 |
| 三处反向题型 | mode_full_risk_profile 51%→17%；mode_effect_to_rpn 75%→66%；risk_colloquial 92%→79% | 逐题归因（路由错？解析错？），决定修复或写进第 6 章局限 |
| 上下文精确率/证据召回率低于朴素基线 | 电池 Full 55.86%/73.27% vs LLM+表格 100%/98.80% | 解释：LLM+表格 直接把整表塞进上下文，天然"精确率 100%"，但准确率只有 82.40% < 97.80%；需在 5.2 明确口径 |
| 电池专项 Full 耗时反超 baseline | 733ms vs 680ms | 归因：电池题集大量走语义路径，失去路由短路收益；重跑后应消失 |

## 三、实验设计

### 3.1 数据集与题集

| 项 | 内容 |
|---|---|
| 数据集 A | Zenodo 浮式海上风电 FMEA（129 条，主实验 1500 题 + 专项 400 题） |
| 数据集 B | 磷酸铁锂电池 DFMEA（26 条，主实验 500 题 + 专项 200 题） |
| 修正 | 电池专项题集用当前 CSV（`FmeaID=LFP001…`）重新生成 |
| 题集标注字段 | 每题除参考答案外，补：`expected_fields/numbers/terms`、`module_label`、`expected_intent/entities/metric/constraints`、`should_reject`（M4 题） |

### 3.2 模块划分（消融单元 ↔ 代码开关）

| 消融单元 | 语义 | 代码开关 | 状态 |
|---|---|---|---|
| R0 语义优先分流 | 前置口语化/模糊判定 | `QA_ENABLE_SEMANTIC_PRIORITY` | **需新增** |
| M1 事实直答 | 编号/字段精确定位 | `QA_ENABLE_CSV_BASIC` | 已有 |
| M2 规则推演 | 过滤/比较/排序/统计 | `QA_ENABLE_DETERMINISTIC_RULES` | 已有 |
| M3a 查询中间表示 | 意图/槽位解析 + 图/向量分派 | `QA_ENABLE_QUERY_IR` | 已有 |
| M3b 语义检索增强 | 向量召回 + 改写变体 | `QA_ENABLE_SEMANTIC_RETRIEVAL_ENHANCEMENT` | 已有 |
| M4 证据裁决 | 充分性/一致性/可追溯性校验 | `QA_ENABLE_EVIDENCE_ADJUDICATION` | 已有 |
| Route 路由判据 | 按证据形态选择路径 vs 固定顺序 | `QA_ROUTE_MODE=fixed` | **需新增** |

### 3.3 对比实验（baseline vs 本文模型）

| 组 | 模型 | 目的 |
|---|---|---|
| 1 | kg-rag-fmea baseline（图查询 + 向量兜底，无路由） | 无路由、无表示、无裁决的对照 |
| 2 | LLM + 表格上下文（整表塞入） | 朴素生成基线 |
| 3 | LLM 直接回答（不给表） | 无知识基线 |
| 4 | **Full（本文框架）** | 待验证模型 |

每个数据集 × 主实验 + 专项，全部组都跑。

### 3.4 消融实验（模块移除）

| 配置 | 关闭 | 目的 |
|---|---|---|
| Full | 无 | 上限 |
| Full − R0 | 语义优先分流 | R0 贡献 |
| Full − M1 | 事实直答 | M1 贡献 |
| Full − M2 | 规则推演 | M2 贡献 |
| Full − M3a | 查询中间表示 | **创新二贡献** |
| Full − M3b | 语义检索增强 | 语义增强贡献 |
| Full − M4 | 证据裁决 | M4 贡献 |
| Full − ΣMi | R0/M1/M2/M3a/M3b/M4 全关 | 残差下限 |
| Full − Route | 路由判据固定为顺序尝试 | **创新一（判据）贡献** |

### 3.5 专项实验（模块作用面）

| 专项题 | 内容 | 期望路径 |
|---|---|---|
| M1 题 | 编号/字段直答 | csv_basic |
| M2 题 | 过滤/比较/排序 | deterministic_rule |
| M3a 题 | 意图/槽位解析、隐式关系 | structured / graph |
| M3b 题 | 口语化、模糊指代、改写 | semantic_rag |
| M4 题 | 证据充分性/冲突/不足（含应拒答） | 任意 + 裁决 |
| Route 题 | 混合，需选对路径 | 按题型各对应 |

每个专项题集，用 Full 与对应移除臂跑，得到"该模块在其作用面上的增益"。
