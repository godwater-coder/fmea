# 对比实验目录

本目录按模型组织实验结果，用于回答“不同模型边界下效果如何”的问题。

## 模型组

```text
LLM/
baseline/
```

- `LLM`：本地 `qwen2.5:7b` 大模型对照，不使用本文 KG-RAG 系统模块。
- `Baseline`：固定 legacy KG-RAG 对照模型，不参与当前 Full-Mi 模块开关重构。

## 数据集

每个模型组下按数据集继续划分：

```text
zenodo_floating_wind_fmea/
磷酸铁锂电池DFMEA/
```

LLM 组中可能继续区分 `表格上下文回答` 和 `直接回答`。其中 `表格上下文回答` 给 LLM 提供完整标准化 CSV 文本，`直接回答` 只给题面。

## 主要用途

论文中这一部分适合用于说明：

- Full 系统之外的固定对照模型表现；
- 纯 LLM 在有无结构化上下文时的能力边界；
- Baseline 与本文方法之间的总体差距。
